# AI 概念配对闯关（AI Term Match）

《人工智能导论》期末大作业 · 路线 B（学习类小游戏）
作者：郭继辉　班级：软件 244　学号：202400406145

---

## 1. 这是什么

把《人工智能导论》课程里的 **AI 术语**和它的 **释义**配成一对的小游戏。
适合期末复习：一边玩一边记概念，答错的术语会被自动收进「错题本」，下一局优先出现。

## 2. 怎么运行（两种方式，任选其一）

### 方式一：双击打开（最简单，推荐）

```
双击 作品/index.html
```

无需安装任何环境、无需联网、无需命令。Windows / macOS 上用 Chrome、Edge、Firefox、Safari 均可。

> 说明：最高分与错题本存在浏览器 localStorage 里，换浏览器或清缓存会重置，属正常现象。

### 方式二：本地起一个静态服务（可选）

如果某些浏览器对 `file://` 的 localStorage 有限制，可在 `作品/` 目录执行：

```bash
python -m http.server 8000
# 然后浏览器访问 http://localhost:8000
```

## 3. 玩法与规则

| 项目 | 规则 |
|---|---|
| 配对 | 先点**蓝色术语卡**，再点**灰色释义卡**（顺序可反） |
| 得分 | 每组配对 **+100**；连击第 n 次额外 **+20×(n−1)** |
| 扣分 | 配错 **−15 分**，连击清零，该术语写入错题本 |
| 时间奖励 | 全部配对成功时，剩余每秒 **+5 分** |
| 难度 | 入门 6 组 / 70 秒；进阶 8 组 / 85 秒；挑战 10 组 / 100 秒 |
| 结束 | 时间归零（未通关）或全部配对完成（通关）→ 弹出结算面板 |
| 重开 | 结算面板点「再来一局」，或按 `Enter` |

**快捷键**：`1` / `2` / `3` 切换难度，`Enter` 开始或再来一局。

## 4. 目录结构

```
作品/
├── index.html      页面结构（语义化标签 + ARIA 无障碍属性）
├── style.css       样式（CSS 变量控制列数，含 900px / 640px 两级响应式）
├── questions.js    题库（51 组，自建，标注所属章节）
└── game.js         游戏逻辑（状态机 + 计分 + 计时 + 音效 + 存档）
```

模块职责分离：**题库 / 表现 / 逻辑**三个文件互不耦合，替换 `questions.js` 即可换成其它学科的题库（例如软件工程、计算机网络术语）。

## 5. 已实现的功能

- 完整游戏循环：待开始 → 进行中 → 结算 → 重开
- 三档难度，题目随机抽取，每局不重复
- 连击计分 + 时间奖励，结算面板显示：得分 / 配对完成率 / 最高连击 / 配错次数
- **错题本**：配错的术语入库，下一局优先抽到（最多存 30 条）
- **最高分存档**：三档难度分别记录，破纪录有提示
- 即时反馈：选中高亮、配对成功变绿、配错抖动、得分飘字
- 音效：Web Audio 实时合成（无音频素材，零版权风险），可一键静音
- 无障碍：卡片为原生 `<button>`，可键盘 Tab 聚焦 + Enter 触发；支持 `prefers-reduced-motion`
- 适配：桌面 4–5 列 / 平板 4 列 / 手机 2 列

## 6. 已知局限

1. **题库 51 组**，覆盖第一、二、三、四、六、七章；第五章（行业落地案例）以概念为主，暂未单独建题。
2. **单机游戏**，没有后端与在线排行榜；最高分存在本地浏览器。
3. **配对判定**只看「术语卡片 ↔ 释义卡片」是否属于同一组，不支持一题多解（一个术语有多种表述时只认题库里的那一条）。
4. **计时器精度**为 1 秒，切到后台标签页时浏览器会节流，倒计时可能变慢（切回来会接着走）。
5. 题库为自建简写释义（≤34 字），细节不如教材完整，用于「认概念」而非「背定义」。
